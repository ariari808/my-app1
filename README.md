# Мои финансы

Личное приложение для учёта финансов с автообновлением курса НБУ.

## Как это работает
- Каждый день в 12:00 по Киеву GitHub скачивает официальный курс НБУ и обновляет `rates.json`.
- Приложение при открытии читает `rates.json` с того же сайта, а если файла нет, пробует запросить НБУ напрямую.
- Ваши операции хранятся только в браузере на вашем устройстве, в репозиторий они не попадают.

## Заметки
- Если 60 дней в репозитории нет активности, GitHub может отключить расписание. Тогда зайдите во вкладку Actions и включите его снова.
- На iPhone и Android страницу можно добавить на главный экран через меню браузера.
